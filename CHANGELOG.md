- Adjusted brief results styling to accomodate the new placement of the ‘Include results beyond UR Libraries’ toggle button.

##2026-04-22
### Fixed
- Adjusted quick link boxes on landing page in mobile view and updated icon styling.

##2026-03-03
### Fixed
- Fixed issue where custom Publisher facet displayed all metadata lowercase.

##2026-02-11
### Added
- Enabled and styled the Third Iron LibKey / Browzine add-on.

##2026-02-06
### Fixed
- Adjusted CSS rule put in place on 2026-01-01. Rule was interfering with mobile view.

##2026-01-16
### Changed
- Changed Browse Search label from Author to Author / Creator.

##2026-01-14
### Changed
- Converted top-level facet labels to title case for uniformity.

##2026-01-13
### Changed
- Reverted XSL styling of letters to set body font color to black to address printing concerns.

##2026-01-05
### Changed
- Updated favicon.ico file to match the new UR brand standards.

##2026-01-01
### Fixed
- Adjusted CSS for accessibility when NDE interface is zoomed to over 200%. Position of buttons, width of side panels, etc. adjusted for usability and access.

##2025-12-12
### Changed
- Updated the LibChat widget to Chatbot-enhanced version that will allow for branching logic.

##2025-11-05
### Fixed
- Resolved CSS opacity styling issue with Advanced Search and Apply Filters buttons.

##2025-10-29
### Removed
- Rolled back adjustments to full span of online resource links in the full record view. Observed instance where users have to click multiple times for the link to work. Will investigate further before re-implementation.
### Changed
- Updated CSS styling for mobile so that resource types filter bar is more compact and does not wrap, spacing of resource type filter bar elements adjusted for clarity and accessibility, and resolved issue with Resource Recommender items sizing.

##2025-10-20
### Changed
- Updated logo to new University of Rochester branding and slightly tweaked centering of top-bar assets.
- Modified CSS so that the full span of online resource links in the full-record view are clickable, instead of the default smaller label area. This improves accessibility and user UX.
- Updated styling of active quick filter buttons.

##2025-09-30
### Fixed
-Changed margin from -1px to 0px in the .cdk-visually-hidden CSS class. Top menu bar elements were rapidly loading and unloading without user input when displayed in a large aspect ratio (1440 x 2650px).

##2025-09-22
### Changed
-Modified CSS so that the full span of ILL request links in the full-record view are clickable, instead of the default smaller label area. This improves accessibility and user UX.

##2025-09-19
### Changed
-Updated ‘No Online Access’ and ‘Check for available services’ labels to ‘No Online Access – Click to See Request Options’ for better clarity.
